Responsive Landing Page

A modern and responsive landing page built using HTML5 and CSS3.
This project demonstrates the use of Flexbox, responsive design, media queries, and clean UI styling for creating a professional webpage layout.

 Features

- Responsive navigation bar
- Modern hero section with gradient background
- Call-to-action button with hover effects
- Sticky header navigation
- Responsive design for mobile devices
- Clean footer with social links
- Flexbox-based layouts

 Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
